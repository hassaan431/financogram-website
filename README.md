# Financo Website

Welcome to the Financo website project! This is a simple, beginner-friendly static website built with HTML, CSS, and JavaScript.

## Project Structure
- `/index.html` - The homepage of the website.
- `/css/` - Contains styles (like colors and layouts).
- `/js/` - Contains interactive scripts.
- `/calculators/` - Will contain all the financial calculators.
- `/learn/` - Will contain educational articles.
- `/about/` - Will contain the About page.

More instructions will be added as we build the project.
